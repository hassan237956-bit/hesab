# صورت‌های مالی — نسخهٔ گوشی (PWA)

این پوشه فقط «پوستهٔ» نصب‌شدنی برنامه است:

- `index.html` — باز می‌کند و برنامه را از فایل رمزشده می‌سازد
- `app.enc` — برنامه، **رمزشده**؛ فقط با کلیدِ داخل فایل شخصی صاحب برنامه باز می‌شود
- `version.json` — شمارهٔ نسخه (برای به‌روزرسانی خودکار)
- `sw.js`, `manifest.webmanifest`, آیکون‌ها

هیچ اطلاعات مالی، رمز یا داده‌ای در این مخزن نیست.
